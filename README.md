# AWS Toolkit Common

This repo contains shared components for the AWS Toolkits for:

* [JetBrains](https://github.com/aws/aws-toolkit-jetbrains)
* [VS Code](https://github.com/aws/aws-toolkit-vscode/)
* [Visual Studio](https://github.com/aws/aws-toolkit-visual-studio)

## Components

### Telemetry

Telemetry is the first shared component in this repository. [Read about telemetry here.](telemetry/README.md)

## Contributing

If you are looking to contribute to one of the AWS Toolkit projects listed above, please consult the `CONTRIBUTING.md` in their respective repositories. This repo contains internal shared components and is not the primary place for community contributions.

For changes to this repository specifically, please open a pull request with a clear description of the change and its motivation.
