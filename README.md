# AWS Toolkit Common

This repository contains shared components used across the AWS Toolkit family of IDE extensions.

## Supported Toolkits

* [AWS Toolkit for JetBrains](https://github.com/aws/aws-toolkit-jetbrains)
* [AWS Toolkit for VS Code](https://github.com/aws/aws-toolkit-vscode/)
* [AWS Toolkit for Visual Studio](https://github.com/aws/aws-toolkit-visual-studio)

> **Note:** If you're looking to contribute to the above projects, consult their respective `CONTRIBUTING.md` docs. This repo contains internal shared components that most contributors would find uninteresting.

## Components

### Telemetry

Telemetry is the first shared component in this repository. It provides common telemetry definitions and code generation for consistent metrics across all AWS Toolkit extensions.

[Read about telemetry here.](telemetry/README.md)
